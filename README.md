# Drug Labs System

Manage and produce drugs in your FiveM server with ease.

## Features

- Create and manage drug labs
- Produce and sell drugs

## Requirements

- FiveM server
- ESX Framework

## Installation

1. Download the script
2. Place the script in your FiveM server's resources folder
3. Add `start marseille_drug_labs_system` to your server.cfg file

## Usage

### Commands

- `/druglabs` - Opens the drug labs menu

### Permissions

- `drug_labs.admin` - Allows access to the drug labs admin menu

## Configuration

Edit the `config.lua` file to configure the drug labs and selling points.
